## Project Summary

Net Analytics is an NCAA basketball analytics dashboard that allows users to discover, compare, and analyze team/player performances across seasons. Net Analytics is a web-based application based on historical and current NCAA Division 1 basketball data (from a Kaggle dataset) to provide structured access to statistics (e.g., MVP, win/loss records, tournament outcomes). The problem we solve is the lack of a unified, user-friendly platform that integrates advanced analytics into a single interactive application. Net Analytics helps users access, compare, and visualize NCAA data in an intuitive way.
