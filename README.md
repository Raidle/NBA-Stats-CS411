# CS411 Project Scaffold

This is a starter project structure for the CS411 NBA analytics project.

## Stack
- Frontend: React + JavaScript + CSS
- Backend: Python + Flask
- Database: MySQL

## Folders
- `frontend/` contains the React app
- `backend/` contains the Flask API and database connection code

## Quick Start
### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
```
